# 3 Semaines

**Notez ce qui vous semble inhabituel. Si ça dure, on vous le rappelle.**

3 Semaines est une application Android **gratuite**, **sans publicité** et **sans aucune collecte de données**, qui aide à consulter plus tôt quand quelque chose d'inhabituel dure dans le corps (une toux qui traîne, une boule, une fatigue inhabituelle…).

- Vous notez ce que vous avez remarqué, et où, sur une carte du corps.
- L'application compte le temps et vous propose un **auto-contrôle guidé chaque semaine**.
- Si ça dure **plus de 3 semaines** ou si ça s'aggrave, elle vous invite gentiment à consulter, et prépare une **fiche claire pour votre médecin**.
- Elle rappelle aussi les **dépistages** qui vous concernent.

> ⚠️ Cette application **ne remplace pas un médecin**. Elle ne fait aucun diagnostic.
> En cas de douleur forte, de saignement important ou d'urgence, appelez le **15** ou le **112**.

## Télécharger et installer (Android)

1. Ouvrez la page **[Dernière version](https://github.com/wargus47-hash/3-semaines/releases/latest)** sur votre téléphone.
2. Touchez le fichier qui se termine par **`.apk`** pour le télécharger.
3. Ouvrez-le. Si le téléphone le demande, autorisez l'installation depuis votre navigateur.
4. Touchez **Installer**.

## Mettre à jour

Dans l'application : **Réglages → Mise à jour → Chercher une mise à jour**, puis suivez les mêmes étapes.
La nouvelle version s'installe par-dessus l'ancienne : **vos notes, photos et réglages sont conservés**.
Par précaution, vous pouvez d'abord créer une sauvegarde (Réglages → Sauvegarde).

## Confidentialité

- Tout reste sur votre téléphone, dans une base chiffrée.
- L'application **n'a pas le droit d'accéder à Internet** : pas de compte, pas de serveur, pas de publicité, pas de mesure d'audience.
- Les photos restent dans l'application, jamais dans votre galerie.
- Les rappels ne contiennent jamais d'information de santé.
